# 단어 탐정 (word-detective)

12세 안팎 아이가 영어 단어를 재미있게 익히게 하는 안드로이드 앱. 개인(가족)용.

- 단어장 사진 → 영어 단어·한국어 뜻 읽기 (구글 ML Kit 한국어 글자 인식, 휴대폰 안에서 동작). 읽은 뒤 확인·고치기. 직접 입력·붙여넣기도 가능
- 공부 방식: 괴도아빠가 세 가지를 섞어 묻는다 — 영어를 들려주고 뜻 묻기 / 뜻을 말해 주고 영어 묻기 / 스펠링 묻기. 답은 말(음성 인식), 글자, 보기 고르기
- 처음 보는 단어는 쪼코가 '단서 카드'로 먼저 보여 줌. 틀린 단어는 그 판 끝에 한 번 더, 그리고 '미해결 사건'으로 남음
- 간격 복습(`core/Srs.java`): 맞히면 1·2·4·7·15일 뒤에 다시, 틀리면 처음부터
- 보상: 단서(점수), 탐정 등급(`core/Rank.java`), 연속 출석, 짝 맞추기 게임
- 수사 기록(부모님용): 최근 2주 공부, 자주 틀리는 단어

## 등장인물 (그림은 `tools/art/*.svg` → `python3 tools/svg2vd.py` 로 앱용 그림 생성)

- 탐정: 아이 (여자아이, 흰 모자·양갈래 머리). 이름은 앱에서 직접 짓는다
- 괴도아빠: 문제를 내는 상대역 (붉은 머리띠·가면)
- 괴도의 조력자: 틀렸을 때 정답을 알려 준다 (올림머리)
- 쪼코: 탐정의 강아지(포메라니안). 단서 카드와 힌트 담당
- 저작권이 있는 만화 캐릭터는 쓰지 않는다 (모두 직접 그린 그림)

## 구조

- `core/` : 안드로이드와 무관한 계산 (사진 글자 → 단어 짝 `Lines`, 채점 `Judge`, 복습 `Srs`, 출제 `Quiz`, 저장 형식 `Data`). 시험: `test/T.java`
- 화면은 모두 코드로 만든다(`Ui.java`). 저장은 앱 안 파일 하나(`data.json`, `Store.java`)
- `main`에 올리면 GitHub Actions가 설치 파일(word-detective.apk)을 만들어 `apk` 브랜치에 올리고, 앱이 거기서 새 버전을 받는다(`Updater.java`). 그래서 저장소는 공개
- 로컬 시험: `javac -d /tmp/wd app/src/main/java/kr/word/detective/core/*.java test/T.java && java -cp /tmp/wd T`
